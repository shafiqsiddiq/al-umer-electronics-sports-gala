# Cricket Tournament — Website

Next.js frontend for the 48-team cricket tournament.

## Setup

```powershell
cd D:\cricket-web
npm install
```

Copy `.env.local.example` to `.env.local` if needed. Use a Sanity **Editor** API token for `SANITY_API_TOKEN`.

## Run

```powershell
npm run dev
```

Open http://localhost:3000

## Sanity CMS

Content is managed in a separate project:

```powershell
cd D:\cricket-sanity
npm run dev
```

Studio: http://localhost:3333

## Paths

| App | Folder |
|-----|--------|
| Website | `D:\cricket-web` |
